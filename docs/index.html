¿Qué es?

Corrector de Proyectos es una herramienta para docentes de Formación Profesional que necesitan calificar los proyectos de fin de ciclo de sus alumnos. Permite gestionar alumnos, proyectos y rúbricas, corregir con una cuadrícula de puntuación y generar o imprimir actas de notas.

El sistema distingue tres perfiles: Admin (configuración global), Profesor (gestión de clase y corrección) y Tutor (solo impresión de actas).

Cómo está construido

La implementación sigue la metodología RAG Spec-Driven Development: los prototipos HTML están anotados con números de boceto (sketchNumber), y un pipeline de 6 agentes Claude convierte esos bocetos más una conversación de requisitos en código backend + frontend completamente trazable y testado.

Stack: Bun · Express · TypeScript · PostgreSQL + pgvector · Web Components nativos · Tailwind CSS · bun test.
